# Публикация без постоянно включённого ПК

Готовый проект размещается на Cloudflare Workers с Durable Objects. Состояние таймера, карта и история донатов сохраняются в облаке. GitHub хранит исходники; GitHub Pages может дополнительно размещать страницы виджетов, которые обращаются к тому же облачному серверу. Сам по себе GitHub Pages не выполняет серверную часть.

## Первое развёртывание

Нужны Node.js 22+ и аккаунт Cloudflare. Бесплатный тариф поддерживает SQLite Durable Objects; ограничения описаны в https://developers.cloudflare.com/durable-objects/platform/pricing/ . Покупать домен не требуется.

```powershell
npm install
npx wrangler login
npx wrangler secret put ADMIN_KEY
npm run deploy
```

Для `ADMIN_KEY` используйте случайный ключ длиной не менее 16 символов. Сохраните его в своём менеджере паролей. Он вводится в админ-панели и никогда не должен добавляться в URL виджетов, GitHub или открытый текст конфигурации.

После публикации Wrangler выдаёт HTTPS-адрес `https://twitch-survival-overlays.<ваш-поддомен>.workers.dev`. По этому адресу доступны:

- `/timer.html` — только таймер, прозрачный фон, 1600×700.
- `/map.html` — только карта, прозрачный фон, 1000×1000.
- `/admin.html` — отдельная админ-панель с входом по ключу.
- `/index.html` — ссылки и предпросмотры отдельных виджетов.
- `/preview.html` — общий предпросмотр.

В Moblin добавьте два Browser-виджета с первыми двумя ссылками и разместите их в сцене. Админ-панель открывайте в Safari, не добавляйте её в кадр. Установленное время сразу применяется ко всем подключённым виджетам. Таймер изначально на паузе, 10:00:00.

## GitHub Pages

```powershell
node scripts/prepare-pages.mjs https://twitch-survival-overlays.<ваш-поддомен>.workers.dev
```

Команда сохраняет только публичный адрес сервера в `public/config.js` и копирует публичные файлы в `docs/`. В GitHub Settings → Pages выберите `main` и `/docs`. В `wrangler.jsonc` адрес `https://winsufix2.github.io` уже разрешён для запросов. Если меняете аккаунт GitHub, обновите `ALLOWED_ORIGINS` и повторите развёртывание. Репозиторий не содержит приватного состояния и токенов.

## DonationAlerts

Войдите в админ-панель и откройте «Первое подключение DonationAlerts». В уже авторизованном браузере откройте https://www.donationalerts.com/application/clients и создайте приложение «Таймер выживания». Адрес сайта: https://twitch-survival-overlays.winsufix.workers.dev . Redirect URI: https://twitch-survival-overlays.winsufix.workers.dev/api/donation/callback . Сохраните полученные Client ID и Client Secret в полях закрытой админ-панели. Затем нажмите «Войти через DonationAlerts» и разрешите чтение донатов. Возврат произойдёт в ту же админ-панель. Вход ограничен одноразовым state со сроком 10 минут.

Client Secret, access token и refresh token сохраняются только в закрытом хранилище Durable Object и не возвращаются через публичный или административный API. При истечении access token сервер обновляет его автоматически. Приложение запрашивает только `oauth-donation-index`. Уже готовый access token можно подключить через дополнительный пункт в панели; в этом варианте refresh token отсутствует и повторное подключение при истечении выполняется вручную. Секрет из ссылки виджета оповещений не подходит. Официальная документация: https://www.donationalerts.com/apidoc .

Новые донаты проверяются каждые 5 секунд через Durable Object alarm. Минуты начисляются один раз по идентификатору; рубли до 10 накапливаются. При первом подключении старые записи показываются в истории с отметкой «До подключения» и прибавкой 0. Новые записи показывают реально добавленные минуты. Считаются только RUB. Тесты отмечаются отдельно и не меняют курсор настоящих донатов. В истории максимум 100 записей. Время получения отображается по Москве.

## Откат оформления

В админ-панели нажмите «Прежний плоский вариант». Меняется только оформление надписей, таймер не сбрасывается. «Объёмные надписи» возвращает новый вариант. Также для отдельного источника можно добавить `?style=flat` или `?style=relief`. Исходный комплект версии 1 сохранён отдельно в рабочей папке и в исходном ZIP.

## Локальная проверка

```powershell
npm test
npm start
```

Ссылки: http://127.0.0.1:8766/ и http://127.0.0.1:8766/admin.html . Локальный ключ автоматически создаётся в `private/admin-key.txt`. Для проверки именно Cloudflare runtime используйте `npm run dev:cloud`; локальные секреты задаются в исключённом из Git файле `.dev.vars`.

Виджеты обновляют состояние раз в 3 секунды; цифры отсчитываются плавно на устройстве. При потере соединения показывается маленькая отметка и отсчёт продолжается от последнего состояния. При переподключении время сверяется с сервером. Связь с интернетом необходима для применения изменений и автоматических донатов.

Растровые основы: 1942×809 и 1254×1254 с альфа-каналом. Объём текста создаётся масштабируемыми гранями, бликами и тенями в CSS; цифры остаются живыми. Шрифт Oswald поставляется локально с лицензией OFL. Карта вымышленная, расстановка предварительная, GPS и адреса не используются.

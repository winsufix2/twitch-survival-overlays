# Виджеты выживания для Twitch и Moblin

Два отдельных прозрачных виджета: таймер на состаренных досках и круглая карта с пятью домами и баней. Отдельная админ-панель позволяет установить любое время, управлять отсчётом, менять местоположение, переставлять здания и видеть последние 100 донатов с количеством прибавленных минут.

- Старт: 10 часов на паузе.
- Каждые полные 10 ₽ добавляют 1 минуту; остатки суммируются.
- Объёмные надписи создаются CSS-гранями и тенями; цифры остаются живыми.
- Табличка и все надписи масштабируются одним блоком с пропорциями исходной графики; подписи остаются на досках в высоких и широких окнах.
- Оформление переключается на прежний плоский вариант без сброса отсчёта.
- Данные сохраняются в Cloudflare Durable Objects и доступны с телефона без включённого ПК.
- История донатов доступна только администратору. Ключ и токен DonationAlerts не публикуются в виджетах.
- Карта вымышленная; GPS, адреса и реальные названия улиц не используются.

## Локальный запуск

Нужен Node.js 22+:

```powershell
npm test
npm start
```

Откройте http://127.0.0.1:8766/ . Вход в админ-панель — ключ из автоматически созданного файла `private/admin-key.txt`.

## Подключение в Moblin

Добавьте два отдельных Browser-виджета:

1. `timer.html` — 1600×700, затем уменьшите в сцене.
2. `map.html` — 1000×1000, затем уменьшите в сцене.

Точные ссылки выдаёт главная страница. Админ-панель `admin.html` открывайте в Safari. Для DonationAlerts один раз зарегистрируйте своё приложение, сохраните Client ID и Client Secret в закрытой панели и нажмите «Войти через DonationAlerts». Полученные access token и refresh token сохраняются в закрытом серверном хранилище; обновление токена выполняется автоматически. Также можно подключить готовый OAuth access token с правом `oauth-donation-index`. Реальная интеграция требует авторизации своего аккаунта, без неё работают ручные команды и тестовые донаты.

## Проверка

`npm test` проверяет установку времени, отсчёт и паузу, повторные донаты, остатки рублей, историю, чтение страниц API и границы доступа. Выполнены браузерные проверки установки 02:30:00, тестового доната с +1 минутой, переключения карты на баню и отката оформления; интерфейс проверен при ширине 390px.

Проверен опубликованный Cloudflare API: установка своего времени, прибавка минуты, история, запрет управления без ключа и отказ постороннему origin. Владелец подключил DonationAlerts через OAuth; API успешно читает историю, автоматические проверки продолжаются каждые 5 секунд. Новое реальное поступление после подключения пока не проверялось.

## Графика и лицензия

Основы созданы встроенным image_gen: таймер 1942×809, карта 1254×1254, RGBA. Надписи и отметки отрисовываются отдельно. Промпты и первоначальная визуальная спецификация находятся в [ART-DIRECTION.md](ART-DIRECTION.md). Локально поставляется шрифт Oswald под SIL Open Font License; лицензия в `public/assets/oswald-OFL.txt`.

Исходный комплект версии 1 сохранён в отдельной локальной папке и архиве. Его PNG доступны в `original-v1/` для сравнения и восстановления оформления.
